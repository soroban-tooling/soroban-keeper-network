# Soroban Keeper Network

The Soroban Keeper Network is a permissionless on-chain task registry with an
incentivised keeper network. Protocols register tasks with an escrowed reward;
keepers claim and execute them and are paid from escrow.

This site collects the project's documentation in one place. The source files
live in the repository (`docs/` and the per-package READMEs); this site is
built from them, so every page has an edit link that points at the original.

| Section | What you will find |
|---|---|
| **Concepts** | How the registry, conditions, verifiers, staking, reputation, treasury, governance and the indexer are designed. |
| **Guides** | Task-oriented walkthroughs: the demo, integrating your protocol, batch registration, oracles, migration. |
| **Reference** | Event catalogues, storage layout, the CLI, SDKs and the indexer API. |
| **Operations** | Deploying, running bots and the indexer, CI, fuzzing, audit scope and security reviews. |
